# Shrijeta Global Website

This repository contains the source code for the Shrijeta Global company website. It is a simple, static website built with HTML, CSS, and minimal JavaScript.

## Project Structure

The project consists of three main files:

- `index.html`: This is the main file that contains all the content and structure of the website.
- `styles.css`: This file contains all the visual styling rules for the website, such as colors, fonts, and layout.
- `script.js`: This file contains a small amount of JavaScript to handle interactive elements, such as the mobile navigation menu.

## How to Edit the Website Content

Editing the content of the website is straightforward. You do not need any special tools, just a text editor.

1.  **Open `index.html`:** Open the `index.html` file in a text editor of your choice.
2.  **Find the Text:** Locate the text you wish to change. The file is structured with comments and semantic tags to make this easier. For example, to change the main headline, look for the `<h1>` tag inside the `<section class="hero">`.
3.  **Make Your Changes:** Replace the existing text with your new content.
4.  **Save the File:** Save your changes to the `index.html` file.

To see your changes, simply open the `index.html` file in a web browser (like Chrome, Firefox, or Edge). You may need to refresh the page to see the latest version.

There is no build step or compilation required. All changes are live as soon as you save the file.
